Case Study

Building an AI-Powered Operations Nervous System for a High-Growth SaaS Startup

A single builder designed and deployed an end-to-end operations nervous system for a Series B vertical SaaS company (~150 employees, thousands of practitioners in a regulated industry). Over ~6 months, four workstreams delivered 50+ production automations across Make, n8n, HubSpot Workflows, and the Claude Agent SDK — connecting 12+ previously siloed business systems into a unified, self-documenting operational layer.

The result: zero manual data entry across deals, leads, post-close handoffs, churn tracking, and feedback capture. Every automation fully documented. An AI agent that answers cross-system questions in seconds.

The Client

Series B vertical SaaS serving thousands of practitioners in a regulated industry. Scaling revenue, headcount, and product surface area simultaneously with a lean operations team.

The Problem

Over two years of rapid growth, the company had accumulated 12+ business systems — HubSpot, Intercom, Stripe, ClickUp, Notion, Gong, SmartLead, and several internal tools — none talking to each other. The operational friction was compounding across every team:

  • Sales: No real-time deal visibility, manual lead assignment, dropped post-close handoffs
  • Customer Success: Churn signals buried in unread Slack messages, no structured cancellation data, support feedback forgotten
  • Product: Feedback arriving through 5+ channels with no unified view
  • Operations: Hours per week manually copying data between tools

The company didn't need one automation. It needed an operations nervous system — a connective layer that made information flow automatically between every system, with AI handling the classification, enrichment, and routing that humans couldn't scale.

The Solution: Four Workstreams Over ~6 Months

Workstream 1

Sales Automation Pipeline

End-to-end automation of the sales operations lifecycle, from lead arrival to post-close handoff:

  • Automated lead assignment — round-robin distribution with Slack notifications and CRM sync
  • Deal stage notifications — real-time visibility into pipeline movement
  • Post-close automation — state machine managing the handoff from sales to onboarding
  • Account manager assignment with AI enrichment
  • Churn monitoring — automated detection and alerting
  • Deduplication guards and error handling across every step

Workstream 2

Unified Feedback Intelligence

Five-plus feedback sources collapsed into a single, AI-classified database:

  • Slack feedback capture — emoji reactions trigger AI categorization into structured threads
  • Support conversation capture — Intercom messages flow through the same AI pipeline into the same database
  • Meeting/call capture — auto-ingested from Gong
  • Dynamic category management — categories created and updated directly from Slack
  • Unified Notion database — single surface for product, CS, and leadership

Workstream 3

Customer Success Automation

Structured systems for churn intelligence and support operations:

  • Churn tracking database — AI parsing of cancellation reasons, billing enrichment from Stripe, standardized taxonomy
  • Automated churn outreach — AI-personalized win-back emails tailored by cancellation reason
  • Support intelligence — AI tagging, routing, and enrichment of every support interaction

Workstream 4

Internal AI Operations Agent

A cross-system AI agent built on the Claude Agent SDK running Claude Opus 4:

  • 13 MCP integrations — connecting every major system in the stack
  • Persistent knowledge brain — 6 domain-specific knowledge areas
  • Sub-agent framework — specialized agents for different operational domains
  • Full BigQuery analytics — querying across 3 GCP projects
  • Teachable via .learn — team members extend the agent's knowledge naturally
  • Source code access for automation lineage and debugging

Documentation Standard

Every automation — all 50+ — includes comprehensive documentation:

  • Purpose and context — why this automation exists
  • Mermaid flow diagrams — visual representation of the logic
  • Step-by-step breakdown — what each node does
  • Data dependencies — which systems feed in, which systems receive output
  • Guardrails — what prevents failures, deduplication logic, error paths
  • Operations runbook — how to monitor, troubleshoot, and maintain
  • Cross-references — links to related automations and data flows

Three system-level Complete Flow Maps document how all automations interconnect across the entire operations layer.

Key Insight

The most valuable thing built wasn't any single automation — it was the system of systems.

Each automation is useful alone, but the real leverage comes from the connections between them. A deal closing triggers a notification AND a sequence AND an assignment. A support message triggers classification AND logging AND routing. A cancellation triggers detection AND categorization AND personalized outreach.

Most companies automate in silos. The unlock is automating the connections.
